# Start Here: Publish Your First GitHub Pages Website

This folder contains an editable starter website. You do not need to know Git commands to publish the first version; you can upload the files through the GitHub website.

## Step 1 — Download and extract
Extract the ZIP file on your computer. Keep `index.html`, `style.css`, `script.js`, and `README.md` together in the same folder.

## Step 2 — Create your GitHub account
Visit https://github.com/ and sign up or sign in. Verify your email if asked.

## Step 3 — Create the repository
Recommended easiest option for a personal website:
1. Click **+** near the top-right, then **New repository**.
2. Repository name: `YOUR-USERNAME.github.io` (replace with your exact GitHub username).
3. Choose **Public**.
4. Click **Create repository**.

## Step 4 — Upload your files
1. Open the repository.
2. Choose **Add file → Upload files**.
3. Upload the four files from the extracted folder: `index.html`, `style.css`, `script.js`, `README.md`.
4. Click **Commit changes**.

Make sure `index.html` is in the repository's top/root level, not inside another folder.

## Step 5 — Turn on GitHub Pages
1. Open **Settings** in the repository.
2. Choose **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Click **Save**.

## Step 6 — Open the live site
Wait a few minutes and reload the Pages settings. GitHub should show the published site link. For a personal repository named `YOUR-USERNAME.github.io`, the address is:
`https://YOUR-USERNAME.github.io/`

Anyone with that link can view the public website.

## Step 7 — Personalise it
Open `index.html` on GitHub and click the pencil icon to edit the text. Click **Commit changes** to publish the edit. To change colours and layout, edit `style.css`. Keep the three website files together.

## Step 8 — Check before sharing
- Replace every `Your Name` / `YN` placeholder.
- Replace the sample email and GitHub link.
- Replace sample projects with accurate descriptions.
- Check the site on a phone and laptop.
- Do not publish private details.

## If it does not work
- Confirm the repository is Public.
- Confirm `index.html` is in the root.
- Confirm Pages is set to `main` and `/(root)`.
- Wait a few minutes after committing changes.
- Check the repository's **Actions** tab for a deployment error.

## Learn Git properly after publishing
This first version uses the GitHub website to make editing easier. Next, learn to edit the same files locally and use `git status`, `git add`, `git commit`, and `git push`.
