# My MIS Student Portfolio

A beginner-friendly personal portfolio website built with HTML, CSS, and a little JavaScript. It can be hosted free using GitHub Pages.

## Personalise it first

Search the files and replace these example values:
- `Your Name` with your name or public portfolio name
- `YN` with your initials
- `your.email@example.com` with an email address you want to publish
- `https://github.com/` with your GitHub profile URL
- Sample skills and projects with work you have genuinely done

Do not publish private information such as your home address, phone number, passwords, student ID, or documents containing personal details.

## Files

- `index.html` — page content and sections
- `style.css` — colours, layout, and responsive design
- `script.js` — mobile navigation and current year

## Publish using GitHub Pages

1. Sign in to GitHub.
2. Create a **public** repository. For a personal site, name it exactly `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait a few minutes. Your site should be available at `https://YOUR-USERNAME.github.io/`.

If you instead use a repository named `my-portfolio`, the URL is usually `https://YOUR-USERNAME.github.io/my-portfolio/`.

## Edit it later

1. Open the repository on GitHub.
2. Select a file such as `index.html`.
3. Click the pencil/Edit button.
4. Make changes and click **Commit changes**.
5. Wait a minute or two, then refresh your live site.

You can also edit the files on your computer and later learn to publish changes using Git commands.

## Important

GitHub Pages is for static sites. This template does not include a private database, server-side code, login system, or contact-form backend. The email link opens the visitor's email application.
